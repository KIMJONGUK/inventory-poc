# ⑥-b LLM review — 리뷰 서브에이전트

CI 통과 뒤 **자문 한 번**. 판정이 아니다 — 사실은 ⑥ 에서 이미 났다.
왜 이 자리인가: 종료 조건을 오독하면 그 해석대로 테스트를 써서 **실패 없이 통과**한다.
회차로도 CI 로도 원리적으로 못 잡는 구멍이고, 그 앞에 남은 판정자는 사람뿐이다.

## 어떻게 띄우나

`Agent(subagent_type: "Explore")` — 읽기 전용이고 `Bash`·`Grep`·`Read` 를 쓸 수 있다.
**`fork` 를 쓰지 않는다.** 구현하며 세운 합리화가 그대로 넘어오면 리뷰가 아니다.
갈라야 하는 것은 세션이 아니라 **컨텍스트**다.

돌려받은 다섯 줄은 내가 이슈 댓글에 단다 — 서브에이전트에게 쓰기를 맡기지 않는다.

## 프롬프트 (아래를 채워서 그대로 넘긴다)

```
너는 inventory-poc 의 ⑥-b LLM review 를 맡는다. 판정이 아니라 자문이다 — CI 는 이미 통과했다.
구현한 세션과 별도 컨텍스트라는 것이 이 리뷰의 존재 이유다. 코드를 고치지 말고 관찰만 남겨라.

대상: 이슈 #<N> · PR #<PR> · 브랜치 <branch> · 루프 <n>/<N>

먼저 읽어라:
- `gh issue view <N>` — 계약 6개 항목. 3번(종료 조건 네 줄) · 4번(테스트 이름) · 5번(범위)이 기준이다
- `gh pr diff <PR>` — 실제 변경
- 필요하면 diff 에 나온 파일의 주변 코드와 `docs/harness/loop.md` §6-b

보는 것 / 안 보는 것:
| 본다 | 안 본다 (CI 몫) |
|---|---|
| 종료 조건 네 줄이 **말한 그대로** 구현됐나 | 타입 · 린트 · 빌드 |
| 테스트가 종료 조건을 판정하나 · **구현을 따라 쓰였나** | 테스트 통과 여부 |
| 계약 5번 범위를 넘었나 | 커버리지 · 성능 |
| 배경(1번)의 의도를 실제로 해결했나 | |

가장 중요한 질문: **종료 조건 줄 ↔ 붙은 테스트 ↔ 구현, 셋이 같은 것을 말하나.**
테스트가 구현을 보고 거꾸로 쓰였으면 무엇을 해도 통과한다. 조건부 expect · 씨앗에 박힌 숫자 ·
구현 내부 표현을 그대로 베낀 기대값이 그 냄새다.

출력 — 머리글 한 줄 + 본문 네 줄. 본문은 계약 3번 네 줄과 1:1, 순서 고정(정상·경계·거부·불변).
각 줄에 **근거 위치**(파일:줄)를 댄다. 그 뒤에 관찰이 더 있으면 `- ` 불릿으로 몇 줄 붙여도 된다.

  LLM review · #<N> · 루프 <n>/<N> · 범위 ✓ · 권고 ① 머지
  정상 ✓ src/lib/shipment.ts:42 ↔ tests/shipment.test.ts:12 — 임박 로트부터 차감
  경계 ✓ tests/shipment.test.ts:18 — 보유 = 요청일 때 통과
  거부 ⚠ Error 를 던지는데 계약은 OutOfStockError — 지정 에러가 아님
  불변 ? 재고 합 불변을 판정하는 테스트를 못 찾음

표식:
- `✓` 종료 조건 줄 ↔ 테스트 ↔ 구현 셋이 같은 것을 말한다. 근거 위치를 댈 수 있다
- `?` 근거를 못 찾았다 — 판정하는 테스트가 없거나 diff 에서 확인 불가
- `⚠` 어긋나 보인다 — 테스트가 구현을 따라 쓰였거나, 다른 것을 판정한다

**「통과」·「실패」라고 쓰지 마라** — 리뷰가 남기는 것은 관찰뿐이다.
못 본 줄도 `?` 로 남겨라. 생략하면 침묵과 확인이 구분되지 않는다.
범위와 권고는 **머리글에** 둔다 — 본문 네 줄은 종료 조건 전용이다.

권고는 아래 셋 중 하나를 가리킬 뿐이고 새 갈래를 만들지 않는다. 고르는 것은 사람이다.
- 네 줄 `✓` · 범위 `✓` → `① 머지`
- `⚠` 하나 이상 · 계약은 그대로 → `② 다시 구현`
- 종료 조건이 배경(1번) 의도와 다름 → `③ 사람 판단`
- `?` 만 있고 `⚠` 는 없음 → `보류` (근거를 확인하고 고른다)

마지막에 이 줄을 붙여라:
  ---
  리뷰어: 별도 컨텍스트 (구현 세션과 분리) · CI 통과 1건당 1회 · 회차를 쓰지 않는다

다섯 줄(+불릿)만 최종 응답으로 돌려라. 파일을 만들지 말고 댓글도 달지 마라.
```

## 받은 뒤

1. 이슈 댓글에 그대로 단다 (원본) → PR 코멘트에 복사
2. 권고를 사람에게 전하고 **갈래 셋을 제시한 뒤 멈춘다**
3. 회차는 변하지 않는다. `②` 를 사람이 고르면 고쳐서 verify 를 돌릴 때 n+1 이다

**같은 초록불에 리뷰를 두 번 부르지 않는다.** CI 잡으로도 만들지 않는다 —
잡이 되면 초록불·빨간불이 되어 자문이 게이트로 변한다.
